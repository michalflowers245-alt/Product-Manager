# Quickstart

## 1. 先选模块

- 想判断一个想法值不值得做：`pm-discover`
- 想做真实用户访谈：`pm-interview`
- 想把需求整理成文档：`pm-prd`
- 想把范围压成 MVP：`pm-prioritize`
- 想补页面结构和文案：`pm-ux-copy`
- 想做上线与反馈闭环：`pm-launch-loop`
- 想把项目写进简历和作品集：`pm-portfolio`

## 2. 推荐调用顺序

1. `pm-discover`
2. `pm-interview`
3. `pm-prd`
4. `pm-prioritize`
5. `pm-ux-copy`
6. `pm-launch-loop`
7. `pm-portfolio`

## 3. 最小工作流

1. 用一句话写出你的产品想法
2. 用 `pm-discover` 判断它值不值得进入验证
3. 用 `pm-interview` 生成访谈提纲并拿到一轮真实反馈
4. 用 `pm-prd` 产出第一版 PRD
5. 用 `pm-prioritize` 压出本版 P0
6. 用 `pm-ux-copy` 补首页、核心页与关键状态文案
7. 用 `pm-launch-loop` 做上线前检查与首周迭代
8. 用 `pm-portfolio` 把过程整理成案例

## 4. 建议搭配

- 新手第一次使用时，优先从 `docs/examples/` 对照着看
- 如果需求还很乱，不要一开始就跳到 `pm-prd`
- 如果功能已经明显失控，先用 `pm-prioritize`
- 如果项目已经做完，直接用 `pm-portfolio` 补求职包装

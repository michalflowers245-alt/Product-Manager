# pm-portfolio

默认中文输出。
你的任务是把真实项目转成高可信案例，而不是夸大。

## 必须输出

1. 一句话项目摘要
2. 3 条简历 bullet
3. 一页案例复盘结构
4. 5 个高频面试问题与回答

- 参考方法：`references/portfolio-principles.md`
- 输出模板：`templates/case-study-template.md`

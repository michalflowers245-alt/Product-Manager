# pm-ux-copy

默认中文输出。

这不是视觉稿生成器，而是 PM 视角的页面结构与交互文案工具。

## 必须输出

1. 页面目标
2. 信息架构
3. 页面骨架
4. 主 CTA / 次 CTA
5. 表单字段
6. 空状态
7. 错误状态
8. 成功状态
9. 信任要素
10. 可访问性提醒

## 原则

- UI 是表象，UX 是本质
- 先讲用户场景，再讲页面模块
- 不为了“高级感”牺牲可理解性
